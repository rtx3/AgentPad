02/ DOCTRINE

PARALLEL AGENTS. STATUS = CONSOLE.

AgentPad is engineered for developers who keep long-running AI coding sessions open all day. It does not try to replace the editor; it puts the two things that ever matter — what's happening and what to do next — where your eyes already land.

01/

GLANCE,
DON'T SWITCH.

Coloured dots in the menu bar read out Working, Calling API or Idle. Multi-project work stops requiring Cmd-Tab to learn who is busy.

SIGNALLIVE
02/

TELEMETRY.

Reads the JSONL session tail the agent writes itself. PTY probe via Accessibility only kicks in as fallback. The network is left untouched.

03/ AGENT.MONITOR

THE RADAR IN THE BAR.

Three states — Working, Calling API, Idle. The smallest vocabulary that still tells you exactly what every session in the fleet wants from you.

MONITOR / 03·A LIVE TAIL · -F
W
WORKING
A shell command is running, a tool call is in flight, or there's an unclosed tool_result waiting for the model to come back.
PRIORITY · 1
A

Request open or response streaming. Takes priority over Idle so the live signal arrives at your eye first.
PRIORITY · 2

04/ CONTROLLER.REMOTE

CONTROLLER = DECIDER.

Per-app profiles keep bindings honest. Terminal, Cursor and your browser each remember their own map. Pick up a game and any passthrough-capable controller drops cleanly back into native gamepad mode.
